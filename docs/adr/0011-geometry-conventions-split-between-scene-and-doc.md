# Geometry conventions: the scene enforces what it can, one doc holds the author's choices

[Research 0005](../research/0005-geometria-notation-conventions.md) established how a Polish klasy 4–8 figure marks itself up, and those conventions have to hold in Topics nobody has written yet. We decided the scene schema owns every convention it can make unwriteable — the łuk z kropką right-angle marker from one helper shared by `RightAngle` and `Altitude`, a height drawn solid when its foot lands on the base and dashed when it lands outside, `S` as a circle centre's default label, and fixed unknown symbols carried on the annotation (`α β γ` for angles and `a b c` for sides, both in figure order; `h`, `r`, `d`). [geometry-conventions.md](../../backend/docs/geometry-conventions.md) owns only what the schema cannot reach, mostly question prose, and lists each CKE convention the app deliberately does not follow (#284).

**Considered options:** schema only (rejected — the symbol named in the prompt, whether an equality is stated or drawn, and how sides are named all sit outside the drawing); a doc only (rejected — conventions the code could rule out would depend on being read); one conventions doc per Chapter (rejected — the scene, the number line's shared Canvas from ADR-0010, and Unit rules all span Chapters, so each rule would be copied or reached through a hop with nothing in it).

**Consequences:** The doc never restates a schema-owned rule, and a primitive for a rejected convention is deleted rather than documented as unused — `ParallelMarks` goes. #293's pooled letter for an unknown length is overturned: every unknown has one fixed symbol, and the prose still reads it off the annotation so the two cannot drift. Solid versus dashed is derived from the geometry, so an interior height added to an already-drawn figure (CKE E8-23 Zadanie 12) cannot be drawn dashed; an author flag is the known extension once a Topic needs it. Equal sides and angles default to the prose, with ticks on the Levels chosen for them, and equal-angle marking is built when the first Topic needs it. Research 0003 and 0005 stay as findings, bannered to point at the doc.
