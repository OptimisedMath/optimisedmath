Geometria scene schema — prototype gallery

Ticket #211. Every figure below is produced by the code shown under it: the generator states maths, the constructor derives the geometry, and the label text is read back off the constructed figure. The figure strokes are currentColor, so dark mode costs nothing.

TOPIC 130

Pole trójkąta — wysokość wewnątrz

The recommended vertical slice. Base and height are the constructor's own arguments, so the label and the drawing cannot disagree.

fig = G.Triangle.base_height(base=8, height=5, apex_frac=0.3)
scene = R.Scene(fig, [
    R.Outline(),
    R.VertexLabels(),
    R.EdgeLabel("AB", unit_label="cm"),
    R.Altitude(apex="C", base="AB", unit_label="cm"),
])

Rodzaje trójkątów — równoramienny
